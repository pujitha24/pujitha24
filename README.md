### 🧰 Projects
- **[contribpolicy](https://github.com/pujitha24/contribpolicy)**: find a repository's rules for AI-assisted contributions (CONTRIBUTING, AGENTS.md, linked AI policies, org-level policies such as Kubernetes') and lint a PR against them before you push. Python, deterministic, no API key.
- **[ai-contribution-check](https://github.com/pujitha24/ai-contribution-check)**: the maintainer side. A GitHub Action that checks incoming PRs against your project's AI contribution policy (disclosure, `Assisted-by` / co-author trailers, DCO, signed commits).
- **[radius-recipe-test](https://github.com/pujitha24/radius-recipe-test)**: `rrt` runs the Radius resource-types-contrib recipe tests on a local kind cluster the way CI does, with readiness waits and verified cleanup.
